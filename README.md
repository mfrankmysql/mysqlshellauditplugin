# MySQL Audit Tool Plugin

Independent MySQL Shell plugin for creating and assigning MySQL Enterprise Audit filters through an interactive wizard.

## Status

## Requirements

- MySQL Shell with Python plugin support
- MySQL Enterprise Audit plugin or audit log component installed on the target server
- Sufficient privileges to manage audit filters and audit user assignments
